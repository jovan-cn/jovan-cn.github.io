The author implements the end-to-end interactive process viewer based on the ncursor library and is no longer a simple terminal command-line program, more like a product with a product level design for windows, menus, sets, etc.Be more friendly to users.

<h3><center>Rationale</center></h3>

1. Elegant code is a good project to learn C language and learn how to achieve object-oriented programming across platforms in C language
2. Product is well designed, and the author has elegant implementation of windows, panels, menues, bar and other components through design mode
